Windows安裝免安裝版的MongoDB

下載網址

MongoDB Community Downloads | MongoDB

配置變數

新增對應的資料夾

  • data/db 用來存放資料
  • data/log/mongodb.log 用來存放日誌

修改 mongodb.conf配置檔案

建立一個mongodb.conf的檔案在資料夾中 , 並新增以下內容

# 資料的位置
dbpath=../data/db
# 日誌的位置
logpath=../data/log/mongodb.log

啟動

進到 mongodb/bin 輸入以下指令

mongod.exe --config "../mongodb.conf"

開啟瀏覽器

http://localhost:27017/

出現 It looks like you are trying to access MongoDB over HTTP on the native driver port. 表示啟動成功
