# 冒險者、具體能力、專案與 Blog 串接

## 需求與範圍

以私人冒險者養成為中心，Blog 作為長期任務與公開成果入口。新增大技能下的具體能力，關聯來源、專案、文章與實作證據；沿用現有 RPG 視覺、文章 EXP 與部署流程。

首批公開能力 requirement-acceptance 歸入 software-design，對應私人 architecture。現有 Prototype 文章保留未實作限制，公開能力為待練習；記帳作品只呈現準備中的規格草稿，不宣稱本人已實作。

## 驗收

能力與文章／技能／作品可往返；未知及重複能力 ID 被攔截，草稿不公開；關聯與標籤重疊只計一次，能力及作品不計文章數。舊文章沒有 abilities 仍正常。

本輪應執行網站統一驗證、能力關聯案例、桌面／手機與明暗模式閱讀、鍵盤導覽。結果將於實測後補入；不沿用前次驗收冒充本輪。

## 發布與限制

本機修改與預覽尚未推送或部署。私人日誌、目標、原始證據與 Vault 路徑不輸出到公開頁。未重新觀看影片或執行 Java／Spring／Vue 教學，也沒有新增後端服務。
