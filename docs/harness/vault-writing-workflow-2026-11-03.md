# 文獻到 Blog 的寫作流程與 Prototype 試作

## 需求與範圍

- 使用者要求將網站搬入私人 Vault，保留獨立 Git；私人草稿與選題由 Vault 管理，定稿由本倉庫管理。
- 從既有 Prototype 影片筆記另寫新文章，原文獻保留。這次是明確授權的新敘事，不套用完整原稿匯入的保真模式。
- 文章以問題、原型選擇、A–D 反饋及交接組織內容；作者案例與整理者推論分開，練習明示尚未執行。
- 本輪只本機驗收，不提交、推送、部署或發放 XP；不修改既有 138 篇文章。

## 來源與內容轉換

- 原始依據是 Matt Pocock 的影片 `https://www.youtube.com/watch?v=n0VhIVtviC0`，及本輪實際讀取的既有完整文獻筆記。
- 原筆記記錄已讀英文自動字幕 0:00–10:57 與關鍵畫面；本輪沒有重新觀看全片、逐一重驗時間或查核現行技能倉庫。
- 新文章保留案例來源、關鍵時間連結與讀者需要知道的限制。沒有沿用私人 MOC、Notion、RPG、維護頁或本機路徑，沒有複製附件。
- 新文章日期為 2026-11-03；舊文日期、路徑、slug 與正文保留。
- `docs/note-review.json` 的 `published: true` 和文章 `draft: false` 表示納入正式建置；不是宣稱已部署。這篇仍只在本機。
