補齊原空白術語，修正 ping、Socket 與數位簽章的混淆。

<!--more-->

適用：工程名詞閱讀與跨團隊溝通；具體產品實作以對應規格為準。

## 網路與服務

| 名詞 | 用途與邊界 |
| --- | --- |
| SNAT／DNAT | 改來源／目的地址；常見於出網與port轉送 |
| TCP／UDP | 可靠有序位元組流／無連線datagram，各有使用代價 |
| Socket | 程式使用的網路端點抽象，不是單一協定 |
| Packet | 網路傳輸單位，與應用訊息／檔案不必一對一 |
| Handshake | 連線或協定協商流程，如TCP／TLS |
| Proxy／Reverse proxy | 代表客戶端／代表服務端轉送 |
| Load balancer | 依規則分配流量，仍需健康檢查與狀態設計 |
| WAF | Web流量的規則／檢測層，不取代應用授權 |
| ISP | 網際網路服務供應商 |
| Instance | 正在運作的服務或物件例項，依情境說清楚 |
| DTLS／RTP | datagram安全傳輸／即時媒體傳輸相關協定 |

## 加密、雜湊與簽章

對稱加密如AES以共享秘密保護機密性；非對稱機制使用公／私鑰，但「任何私鑰加密都能用公鑰解密」不是通用簽章說明。數字簽章驗證完整性與簽署者持有對應私鑰，不能當保密加密。

憑證把身份／網域與公鑰關聯，依CA與驗證鏈建立信任；雙因子認證使用兩類因素，兩個密碼仍不是兩種因素。Code signing用於確認程式來源與完整性，不保證程式沒有惡意。

## 常見診斷用語

ping測ICMP回應，不代表主機「開ping服務」，沒回不一定不存在；測TCP port用Test-NetConnection或適當client，連上port仍不證明業務正常。policy指一組規則，sent/side等一般英文需連具體上下文，不單獨列成技術概念。

Code snippet是可說明某一行為的程式片段；複製前核對前置環境與驗證範圍。討論時把名詞放在例子中，例如「由reverse proxy做TLS終止，再把HTTP轉發到內網instance」，比只堆縮寫容易確認理解。
